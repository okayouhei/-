# 夜の水商売・無料案内所向け公式LINEアカウント開設ガイド

このリポジトリは、夜の繁華街で水商売のお店探しをサポートする「無料案内所」が公式LINEアカウントを立ち上げ、集客・接客・安全対策を強化するための手順をまとめています。現場スタッフが迷わず準備・開設・運用できるよう、順序立てて進めてください。

## 1. 事前準備
- **ブランドコンセプトの整理**: 対応エリア（例: 歌舞伎町、中洲など）、案内できる業態（キャバクラ、クラブ、ガールズバー、ホストクラブ 等）、無料案内所としての差別化ポイントを文章化する。
- **必要素材の収集**: ロゴ、店内・街並み写真、24時間対応の電話番号、利用規約・個人情報保護方針、深夜営業に関する注意喚起テキストを用意する。
- **運用体制の確認**: 夜間帯の問い合わせに対応できるスタッフ体制、即時返信が難しい場合のエスカレーションフロー、悪質利用者への対応マニュアルを準備する。

## 2. LINE公式アカウントの作成
1. [LINE Official Account Manager](https://manager.line.biz/) にログインし、「アカウントを作成」>「新規作成」を選択。
2. 業種カテゴリは「観光」または「サービス業」を選び、アカウント名・プロフィール文には無料案内所であることと対応エリアを明記する。
3. `設定 > アカウント設定` で以下を調整する。
   - 連絡先電話番号・営業時間（例: 18:00〜翌5:00）を登録
   - 応答モードは「チャット」を基本とし、チャットボットを併用する場合は有人対応への切り替え方法を明確化
   - スタッフのLINEアカウントを「運用担当」として招待し、深夜帯の交代シフトを設定

## 3. 友だち追加導線の整備
- QRコード・友だち追加リンクを印刷ポスター、店頭サイネージ、タクシー広告、Webサイトに掲示し、来街者がすぐ追加できるようにする。
- LINEミニアプリやクーポン配布を活用し、各店舗の初回利用特典を告知する。
- ホテル・飲食店と連携し、チェックイン時に公式LINE案内カードを配布してもらう。

## 4. 応答・メッセージ設計
- **あいさつメッセージ**: 「現在営業中の店舗一覧」「料金目安」「安心して楽しむための注意事項」への導線を含める。
- **リッチメニュー**: 「今すぐ案内を受ける」「エリア別おすすめ」「本日のイベント」「トラブル相談窓口」といったボタンを配置する。
- **自動応答/チャットボット**: よくある質問（料金相場、営業中の店舗、送迎サービスの有無 等）に自動で回答し、詳細案内はスタッフに接続する。
- **配信メッセージ**: 週末の混雑状況、限定イベント、店舗の入れ替わり情報を定期配信し、深夜帯はプッシュ通知頻度を抑える。

## 5. セキュリティ・コンプライアンス
- 風俗営業等の規制や地方自治体の案内所条例を確認し、LINE上の表現が法令に適合しているかチェックする。
- 個人情報の取り扱いを明文化し、来店履歴・顧客属性の利用目的を必ず明示する。
- 不適切な利用（未成年、飲酒運転、ぼったくり等）を発見した場合の対応フローをマニュアル化し、スタッフに共有する。

## 6. 運用と改善
- LINE Official Account Manager の分析レポートで友だち追加数、応答時間、コンバージョン（来店数）を毎週確認する。
- 現場スタッフからのフィードバックをもとにリッチメニューや自動応答フローを更新し、深夜のピーク時間帯に合わせたメッセージを最適化する。
- 提携店舗との情報連携シートを作成し、在籍キャスト情報や料金変更を即時反映できる体制を整える。

## 7. リスク管理と教育
- 深夜のトラブル対応マニュアル、緊急連絡先、警察・消防との連絡手順をLINEで共有できるようにする。
- 新人スタッフ向けに操作マニュアルとNG対応例を用意し、定期的に教育ミーティングを行う。
- トラブルやクレームの履歴をスプレッドシートで管理し、再発防止策を運用ルールに反映する。
