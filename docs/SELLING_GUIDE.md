# AI名刺カードアプリ 販売ガイド

このドキュメントは、VST AIカード風のAI名刺カードアプリ「AI Card Lab」を販売・展開するための実務的な手順をまとめています。個人の制作・販売や、代理店として複数クライアントへ展開する際に活用してください。

## 1. プロダクト概要
- **提供価値**: AIによるコピー生成と即時プレビューで、デザインと文章の両面からデジタル名刺を作成。
- **ターゲット**: フリーランス、スモールビジネス、オンラインでの自己紹介を強化したい店舗スタッフ。
- **利用シーン**: LINEプロフィール、SNSシェア、QRコード付きのデジタル配布など。

## 2. 必要な準備物
1. **ドメイン・ホスティング**: 静的サイトとして提供できるため、Netlify・Vercel・Cloudflare Pagesなどで無料/低コスト運用が可能。
2. **課金導線**: BASE、STORESなどのECプラットフォーム、またはStripe Checkoutを活用し、テンプレート追加やカスタム制作を有料化。
3. **サンプルカード**: 業種別（美容、飲食、B2B等）のサンプルを5〜10種類用意し、購入前に完成イメージを提示。
4. **利用規約・プライバシーポリシー**: 個人情報の取り扱いとAI生成文の責任範囲を明記。

## 4. 営業・集客のポイント
- **LINE連携**: 公式アカウントから申込フォームへ誘導し、作成したカードを配信サンプルとして送付。
- **Instagram**: Before/After投稿やリールで制作過程を紹介し、プロフィールリンクから購入導線を設置。
- **無料体験**: フリープランとして自己入力・ダウンロードを開放し、商用利用やテンプレート追加は有料化。
- **口コミ強化**: 納品後にGoogleフォームでレビューを集め、掲載許可を得た上でサイト・SNSで紹介。

## 5. 運用とサポート
- カスタマー対応テンプレ: よくある質問（支払方法、納期、修正回数）をテンプレ化して即返信。
- 更新管理: 顧客ごとにスプレッドシートを作成し、納品日・テンプレ・カラーコードを管理。
- バージョンアップ: テンプレートやコピー提案のバリエーションを四半期ごとに追加し、サブスク価値を維持。

## 6. 法的・倫理的な注意点
- 名刺に記載する情報の正確性は顧客に確認し、虚偽表示がないようにする。
- AIコピーはオリジナル性確保のため、納品前に固有名詞・専門用語が正しいか最終チェックを実施。
- 個人情報を保存する際はパスワード管理ツールや暗号化ストレージを使用。
